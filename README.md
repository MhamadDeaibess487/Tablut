# Tablut — Jeu de stratégie en Java

## Description

Projet universitaire de développement d'un jeu de stratégie inspiré du Tablut, un jeu de plateau traditionnel appartenant à la famille des jeux Tafl.

Le projet a été réalisé en équipe dans le cadre de l'UE Programmation 6 de la Licence 3 Informatique à l'Université Grenoble Alpes (2025–2026).

Il combine programmation orientée objet, logique de jeu, interface homme-machine et étude de l'intelligence artificielle.

## Le jeu Tablut

Le Tablut est un jeu de stratégie asymétrique opposant deux camps :

- **Les défenseurs :** doivent protéger leur roi et l'amener jusqu'à une case permettant sa fuite.
- **Les attaquants :** doivent empêcher la fuite du roi et parvenir à le capturer.

Les joueurs déplacent leurs pièces sur un plateau et doivent adapter leur stratégie aux déplacements adverses.

## Axes du projet

### Logique du jeu

Modélisation d'un jeu de plateau stratégique, de ses pièces et de ses règles.

### Interface homme-machine

Conception et étude de l'interaction entre l'utilisateur et le jeu.

### Intelligence artificielle

Étude de l'intégration de mécanismes d'intelligence artificielle dans le contexte d'un jeu de stratégie.

Les détails des algorithmes sont documentés dans `Dossier IA.pdf`.

## Exécution

Le dépôt contient une archive Java exécutable ou distribuable :

```bash
java -jar Tablut.jar
```

Cette commande nécessite une installation de Java compatible. Le mode de lancement exact reste à confirmer.
